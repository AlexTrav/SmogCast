# SmogCast

[![CI](https://github.com/AlexTrav/SmogCast/actions/workflows/ci.yml/badge.svg)](https://github.com/AlexTrav/SmogCast/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Рубежное задание РК-2 по курсу «Технологии разработки программного обеспечения для систем
реального времени»: система прогнозирования временных рядов – концентрации мелкодисперсных
частиц PM2.5 в воздухе Алматы на 1–3 суток вперёд по моделям ARIMA, Prophet и LSTM с дашбордом
и ежечасным обновлением данных.

Автор: **Алексей Нерезов**.

> Неофициальный студенческий проект: ряд PM2.5 – это оценка модели CAMS (Copernicus),
> а не замеры станций, и прогноз не заменяет официальные данные Казгидромета.

## Что сделано

Проект завершён и работает в интернете: сайт – https://alextrav.github.io/SmogCast/,
API – https://smogcast-backend.onrender.com/docs. Данные и прогнозы обновляются каждый час.

- сбор почасового ряда PM2.5, других загрязнителей и погоды с 01.09.2022 из Open-Meteo,
  инкрементальное обновление, проверка ряда и повторы при сбоях источника – [data/](data/README.md);
- исследование ряда: сезонность, тренды, аномалии, стационарность, связь с погодой,
  однородность источников – [research/](research/README.md);
- живой ряд в Postgres (Neon) с ежечасным обновлением через GitHub Actions по расписанию cron-job.org
  и снимками прогнозов CAMS и погоды – [data/](data/README.md#база-и-ежечасное-обновление);
- честная проверка моделей (скользящее начало прогноза, валидация и отложенный тест по времени):
  базовые модели, ARIMA, Prophet, LSTM, их сравнение и смесь по умолчанию, живые прогнозы всех
  моделей каждый час – [model/](model/README.md). На отложенном годе смесь ошибается в среднем
  на 5,5 мкг/м³ на первые сутки и угадывает уровень воздуха US AQI в 83 % часов;
- API на FastAPI для сайта: текущее состояние, прогнозы, весь ряд, журнал «прогноз → факт», погода
  и факторы смога, «почему такой прогноз», сетка для карты, итоги моделей, производительность и
  пересчёт быстрых моделей по кнопке – [backend/](backend/README.md);
- сайт на Vue 3: живое небо над Алматы, прогноз на три дня простыми словами, советы, почасовая
  лента, график моделей, «Промотать прогноз», история ряда, модели с живым журналом, 2D-карта сетки
  CAMS, производительность; подсказки к каждой цифре, русский, казахский и английский языки,
  работа без сети – [frontend/](frontend/README.md);
- 173 автотеста, CI на каждый push, выкладка сайта и API только после успешных тестов.

**Ограничения.** Ряд – оценка модели CAMS для клетки около 45 × 33 км, а не замеры: весь город –
одна клетка, уличные значения бывают заметно выше. Модели сглаживают пики смога. Бесплатный
сервер API засыпает без посетителей, и первый запрос после сна занимает до минуты.

## Запуск

Нужен только Docker и make:

```bash
make data    # дописать свежие часы ряда и проверить его
make check   # проверить ряд
make test    # автотесты: сбор данных, исследование, модели, API, сайт
make api     # API локально на http://localhost:8000/docs
make site    # сайт локально на http://localhost:5173
```

## Тесты и CI

| Часть | Что проверяется | Тестов | Команда |
|---|---|---|---|
| data | сбор и проверка ряда, повторы при сбоях Open-Meteo, запись в базу и переподключение (Postgres 18 в compose) | 36 | `make -C data test` |
| research | подготовка ряда, сбой CAMS, сезоны | 11 | `make -C research test` |
| model | честная проверка, все модели, живые прогнозы | 41 | `make -C model test` |
| backend | все точки API, кэш и 304, пересчёт и защита (Postgres 18 в compose) | 31 | `make -C backend test` |
| frontend | расчёты сайта, переводы и подсказки на трёх языках (Vitest) | 31 | `make -C frontend test` |
| frontend/e2e | сайт в браузере: страницы, кнопки, подсказки, скриншот-тесты (Playwright) | 23 | `make -C frontend e2e` |

[CI](.github/workflows/ci.yml) на каждый push и pull request гоняет первые пять наборов параллельно в тех же
Docker-образах. Сайт на GitHub Pages и API на Render выкладываются только после зелёного CI. Браузерные тесты
запускаются локально перед правками интерфейса; эталонные скриншоты – `make -C frontend e2e-update`.

## Структура

```
SmogCast/
  data/      – сбор и проверка ряда, сам ряд (series/almaty.csv), запись в базу
  .github/workflows/hourly.yml – ежечасное обновление базы (запускает cron-job.org)
  .github/workflows/ci.yml     – автотесты на каждый push
  .github/workflows/pages.yml  – выкладка сайта после зелёного CI
  research/  – исследование ряда: статистика (results/), рисунки для отчёта
  model/     – каркас проверки, модели прогноза, отчёты с метриками (reports/)
  backend/   – API на FastAPI: только чтение базы для сайта и пересчёт быстрых моделей
  frontend/  – сайт на Vue 3 (GitHub Pages)
  Makefile   – общие команды
```

## Данные

Air quality data: CAMS / Copernicus, weather data: ECMWF IFS, via
[Open-Meteo.com](https://open-meteo.com/) ([CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)).
