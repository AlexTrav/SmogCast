# SmogCast

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Рубежное задание РК-2 по курсу «Технологии разработки программного обеспечения для систем
реального времени»: система прогнозирования временных рядов – концентрации мелкодисперсных
частиц PM2.5 в воздухе Алматы на 1–3 суток вперёд по моделям ARIMA, Prophet и LSTM с дашбордом
и ежечасным обновлением данных.

Автор: **Алексей Нерезов**.

> Неофициальный студенческий проект: ряд PM2.5 – это оценка модели CAMS (Copernicus),
> а не замеры станций, и прогноз не заменяет официальные данные Казгидромета.

## Состояние

Проект в работе. Готово:

- сбор почасового ряда PM2.5, других загрязнителей и погоды с 01.09.2022 из Open-Meteo,
  инкрементальное обновление и проверка ряда – [data/](data/README.md);
- исследование ряда: сезонность, тренды, аномалии, стационарность, связь с погодой,
  однородность источников – [research/](research/README.md);
- живой ряд в Postgres (Neon) с ежечасным обновлением через GitHub Actions и снимками прогнозов
  CAMS и погоды – [data/](data/README.md#база-и-ежечасное-обновление).

Дальше: честная проверка моделей (скользящий бэктест, наивные базовые модели), ARIMA,
Prophet, LSTM, бэкенд FastAPI, дашборд на Vue, деплой.

## Запуск

Нужен только Docker и make:

```bash
make data    # дописать свежие часы ряда и проверить его
make check   # проверить ряд
make test    # автотесты
```

## Структура

```
SmogCast/
  data/      – сбор и проверка ряда, сам ряд (series/almaty.csv), запись в базу
  .github/workflows/hourly.yml – ежечасное обновление базы
  research/  – исследование ряда: статистика (results/), рисунки для отчёта
  Makefile   – общие команды
```

## Данные

Air quality data: CAMS / Copernicus, weather data: ECMWF IFS, via
[Open-Meteo.com](https://open-meteo.com/) ([CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)).
