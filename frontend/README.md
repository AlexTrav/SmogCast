# frontend – сайт SmogCast

Vue 3 + TypeScript + Tailwind CSS 4 + vue-i18n (русский, казахский, английский), графики – Apache ECharts,
иконки – lucide. Данные – из [API](../backend/README.md) на Render. Сайт – https://alextrav.github.io/SmogCast/
(GitHub Pages, [выкладка](../.github/workflows/pages.yml) при каждом push, затрагивающем `frontend/`).

```bash
make dev     # dev-сервер на http://localhost:5173 с горячей перезагрузкой
make test    # автотесты Vitest
make run     # собранный сайт (nginx) на http://localhost:8080
make lock    # обновить package-lock.json после правки package.json
```

Всё запускается в Docker – node_modules на диск не ставится. Адрес API в dev задаёт `.env.development`
(для локального API – `http://localhost:8000`, его поднимает `make -C ../backend run`).
Собранный сайт с локальным API: `make run API=http://localhost:8000`.

## Главная простыми словами

- Карточки «Сегодня / Завтра / Послезавтра»: какой будет день, разброс и когда хуже и лучше всего;
  нажатие на день прокручивает почасовую ленту (как в приложениях погоды) к его первому часу.
- «Когда лучше выйти»: самые чистые 2 часа для прогулки (7:00–22:00) и самый чистый час для проветривания
  сегодня и завтра (`src/utils/outlook.ts`); переключатель «У меня чувствительность к смогу» делает советы
  строже.
- График с моделями – по кнопке «Подробнее»: фон полосами уровней AQI, горизонт 1 / 2 / 3 суток, модели
  галочками для сравнения, разброс и прогноз CAMS – переключателями, подсказка словами, таблица значений и
  «Пересчитать сейчас» (сервер заново считает быстрые модели и показывает время каждой).
- «Промотать прогноз»: небо, дымка и цифра проходят по 72 часам вперёд, ползунок – к любому часу.
- Значки «?» объясняют термины (PM2.5, AQI, разброс, CAMS, норма ВОЗ, смесь); при первом визите – экскурсия
  из четырёх шагов, повтор – «Как читать прогноз».

## Оформление

- Концепция «Небо над Алматы»: первый экран – небо над силуэтом Заилийского Алатау; цвет неба и дымка,
  закрывающая горы, зависят от текущего PM2.5, число частиц в воздухе – тоже; день и ночь – по времени Алматы.
  Предпросмотр для показа: `?sky=day|night&pm=150` (данные API не меняются).
- Палитра своя (`src/style.css`): днём – снежный туман и альпийская синева, ночью – ночное небо, акцент –
  закатный абрикос. Цвета серий графиков проверены на различимость при дальтонизме в обеих темах; уровни
  US AQI всегда показываются цветом вместе с иконкой и подписью.
- Шрифт Onest – локально, в нём есть все казахские буквы (проверено по глифам); цифры в таблицах и плитках –
  одинаковой ширины (tabular-nums).
- Сервер на бесплатном Render засыпает без посетителей: сайт будит его при открытии и, пока он просыпается,
  показывает плашку «Сервер просыпается…» и заготовки блоков. Состояние опрашивается раз в минуту; пока
  нового часа нет, сервер отвечает пустым 304.
- Без сети сайт открывается с последним сохранённым прогнозом: service worker (`public/sw.js`) держит
  оболочку и последние ответы API; сайт можно установить на телефон (`manifest.webmanifest`).
- «Поделиться» рисует карточку 1200×630 с небом и текущим PM2.5 прямо в браузере (canvas): на телефоне
  открывается системное меню, на компьютере картинка скачивается.
- Анимации на CSS: подъём карточек при наведении, прорисовка графика, плавная смена горизонта и моделей,
  волна от нажатия (`v-ripple`), блик на заготовках, параллакс неба при прокрутке, «вдох» чистого неба.
- Доступность: уровни не передаются одним цветом, у прогноза есть таблица значений, видимая рамка фокуса
  для клавиатуры, анимации отключаются при «уменьшить движение» в системе.
